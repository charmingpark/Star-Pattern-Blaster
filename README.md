  # 🌟 Star Pattern Blaster (별 찍기 블래스터)

아케이드 슈팅 게임과 **반복문·재귀 알고리즘 학습**을 결합한 인터랙티브 코딩 교육 게임입니다.  
다양한 별 찍기 패턴으로 구성된 웨이브를 공략하면서, 각 패턴이 어떤 반복문(`for`, `while`)과 조건/재귀 구조로 만들어지는지 실시간으로 확인할 수 있습니다.

---

## ✨ 주요 특징

* **패턴 기반 아케이드 슈팅:** 별 찍기 모양으로 배치된 적/코어 패턴을 공략하며 스테이지를 진행합니다.
* **실시간 코드 뷰어 (Python / C++):** 현재 스테이지의 별 패턴을 출력하는 코드와 루프 변수(`i`, `j`, `n` 등) 흐름을 함께 살펴볼 수 있습니다.
* **한국어 / 영어 UI 지원:** 학습 환경이나 수업 대상에 맞춰 한국어와 영어로 화면 텍스트를 전환할 수 있습니다.
* **백준(BOJ) 별 찍기 시리즈 확장:** 기본 삼각형·피라미드·다이아몬드 외에 나비 모양, 모래시계, 빈 삼각형, 프랙탈 등 다양한 별 찍기 패턴으로 확장할 수 있도록 설계했습니다.

---

## 🧩 수록 및 확장 대상 패턴 예시

| 구분 | 패턴 이름 | 학습 포인트 |
| :--- | :--- | :--- |
| 기본 | 직각삼각형 / 역삼각형 | 중첩 반복문 기본 구조, 증감 조건 |
| 정렬·대칭 | 오른쪽 정렬 삼각형 / 역피라미드 | 공백(`" "`) 출력 루프와 별(`"*"`) 출력 루프 분리 |
| 복합 대칭 | 다이아몬드 / 나비 모양 / 모래시계 | 상·하단 대칭 구조 및 행 인덱스(`i`) 변화 |
| 응용·심화 | 빈 삼각형(테두리) / 프랙탈 별 찍기 | 경계 조건(`j` 위치) 제어 및 분할 정복(재귀) |
